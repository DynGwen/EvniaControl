# Evnia Control 1.0.20

The application interface is now fully in English:

- menu bar interface;
- Options window;
- DDC status and error messages;
- Core Audio status and error messages;
- macOS audio-capture permission description;
- installer messages.

No functional logic has been changed.

The following behavior is preserved exactly from 1.0.19:

- Magic Keyboard brightness and volume steps: 5%;
- Option + Shift fine step: 1%;
- brightness, volume and attenuation persistence;
- software audio attenuation from −60 dB to 0 dB;
- 3 dB attenuation steps;
- full-width AppKit attenuation slider;
- application icon;
- automatic refresh;
- no manual Refresh button.
